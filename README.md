# PawHealth Website

A React and Vite frontend project for a pet-health service website. The repository contains a component-based interface with sections for the hero, services, how-it-works flow, contact form, and footer.

## Technology

React · Vite · JavaScript · CSS

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
npm run preview
```

## Repository maintenance

Dependencies are installed locally from `package.json` and `package-lock.json`. The generated `node_modules/` directory has been removed from source control. Do not commit dependency folders, local environment files, or build output.

## Portfolio context

This is a supporting frontend project and is not part of the core Data Engineering + Analytics portfolio.
